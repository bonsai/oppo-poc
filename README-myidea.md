# myapp

## Intent（何を作りたいか）

集中と休息を25分単位で切り替えるシンプルなポモドーロタイマー。
作業開始のハードルを下げ、1日の作業セッションを可視化する。

## 対象ユーザー

- 在宅勤務・リモートワークで時間管理に苦労している人
- 1タブ・ログイン不要でパッと使いたい人

## 何ができればいいか（MVP）

- 作業25分 / 休憩5分の周期でカウントダウン
- 開始・一時停止・リセット
- 周期が切り替わるとブラウザ通知＋音で知らせる
- 完了セッション数を表示（今日の実績）

## どんな体験にしたいか

- 開いたらすぐ使える（設定画面を挟まない）
- タイマーはボタン1回で開始
- 作業に集中している間は何も考えなくていい

## 対象外（今回はやらない）

- ログイン・アカウント
- 外部サービス連携
- タスク管理・ToDo機能
- 設定の永続化（デフォルトが変えられれば十分）

## 技術スタック

- 単一HTMLファイル（index.html）
- Vanilla JS / CSS
- ブラウザネイティブの Notification API + Web Audio API
- ビルド・依存なし

## 実行

```
# ローカル起動（ESモジュール不要だが、確認用）
python3 -m http.server 8000
# http://127.0.0.1:8000 を開く
```
